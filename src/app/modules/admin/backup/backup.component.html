Backup & Restore

Create local logical JSON snapshots of core marketplace data and restore them when needed. Ideal for local development and disaster recovery of app data.

Heads up: Restore is destructive. It truncates operational tables and reloads them from the selected snapshot. Active users may be disconnected and will need to sign in again. Only restore from a backup you trust.
Backups are stored on the API host under Backup:Directory (default /tmp/EquaMeridianBackups). On Render the disk is ephemeral unless you attach a persistent disk — download important backups to your machine.
