How this works

  • The job runs on the configured interval and expires quotations older than the expiry window.
  • Use "Run Now" to trigger an off-cycle run immediately.
  • Disabling the timer pauses automatic expiry — quotations will need manual handling.
  • Session idle logout is enforced in the browser. Save this page to apply the new idle window.
